Plataforma mobile Peer-to-Peer (P2P) para intermediação e aluguel sob demanda de vagas de garagem privadas. 
O sistema conecta proprietários com espaços ociosos (Anfitriões) a motoristas que buscam estacionamento rápido, 
seguro e geolocalizado, contando com regras de disponibilidade, precificação flexível (por hora, dia ou mês), 
reserva em tempo real e validação de acesso.
